    Esfuerzo

    Los modelos nuevos piensan solos antes de responder. El nivel de esfuerzo (bajo, medio, alto, extra alto o máximo) decide cuánto. Más esfuerzo es más lento y gasta más. Empieza con el valor por defecto y súbelo solo si el resultado no alcanza.

    No pidas «piensa paso a paso»

    Ya lo hacen por dentro. Pedir que escriban su razonamiento puede hacer que se nieguen. Si quieres que piense más, sube el esfuerzo.

    Di cuándo está terminado

    En lugar de «revisa todo muy bien», escribe la meta concreta: «está terminado cuando la página no se sale de la pantalla en el celular». Así no se queda corto ni revisa de más.

    Pide corto si lo quieres corto

    Bajar el esfuerzo no acorta la respuesta. Si quieres algo breve, dilo: «máximo 5 líneas». Y en diseño, nombra los estilos que no quieres; «que no se vea genérico» no basta.

    Precios de la API por millón de tokens. En Claude.ai y Claude Code el uso se descuenta de tu plan y algunos modelos pueden no estar incluidos en todos los planes. Fuentes: resumen de modelos y guía de prompting de Anthropic.

    Prompt
    Es el mensaje que le escribes a Claude. Funciona como darle instrucciones a un compañero nuevo: mientras más claro le dices qué quieres, para quién y cómo, mejor sale el resultado. En la sección «La fórmula» aprendes a armarlo.
    
        
    Skill
    Es un manual guardado que Claude lee solo cuando lo necesita. Como una receta: la escribes una vez y Claude la sigue cada vez que le pides ese plato.
    
        
    Plugin
    Es un paquete que trae varias skills y herramientas juntas. Se parece a instalar una app en tu celular: un clic y ya tienes todo lo que trae.
    
        
    Agente
    Es un Claude con un solo trabajo y sus propias reglas. Por ejemplo, uno que solo revisa errores y otro que solo los arregla, como especialistas de un equipo.
    
        
    Conector
    Es el cable que une a Claude con tus apps, como el correo o Google Drive. Sin conector, Claude solo ve lo que le pegas en el chat.
    
        
    Comando
    Es un atajo que empieza con una barra, por ejemplo /init. Lo escribes en Claude Code y hace algo al instante, sin tener que explicarlo con palabras.
    
        
    Claude.ai y Claude Code
    Claude.ai es el chat que usas en el navegador o en la app. Claude Code es Claude trabajando directo en las carpetas de tu computador: crea, edita y prueba archivos por ti.
    
        
    Terminal
    Es la ventana donde se escriben comandos en el computador. En Windows se llama PowerShell y en Mac se llama Terminal. Solo copias, pegas y presionas Enter.

    Antes de instalar
    
      
    Cuatro revisiones que evitan sustos
    
      
    Una skill o un plugin pueden leer archivos y ejecutar comandos con tus permisos. Revisa esto antes de instalar algo que no venga de Anthropic.
    
      
    
        
    Verifica el origen
    Prefiere el marketplace oficial o repos con dueño identificable, historial de cambios y licencia.
    
        
    Lee el SKILL.md completo
    Busca instrucciones de enviar datos a otros sitios, descargar archivos o ejecutar scripts que no esperas.
    
        
    Nada de claves en archivos
    Ninguna skill necesita tu contraseña ni tokens escritos dentro. Si te los pide, no la instales.
    
        
    Prueba con datos de ejemplo
    Primera ejecución con información ficticia. Revisa el resultado antes de usarla con datos de clientes.
